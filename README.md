# نظام إدارة طلبات لازم للخدمات الطبية

## التشغيل في VS Code
1. افتح مجلد المشروع في VS Code
2. ثبّت إضافة **Live Server**
3. كليك يمين على `index.html` → **Open with Live Server**

بديل: `python3 -m http.server 5500` ثم افتح `http://localhost:5500`

⚠️ لا تفتح `index.html` بالنقر المزدوج (رابط `file://`) — استخدم خادماً محلياً.

## الملفات
| الملف | المحتوى |
|-------|---------|
| `index.html` | هيكل الصفحات |
| `style.css` | التصميم والتنسيقات |
| `app.js` | منطق التطبيق (الدخول، الطلبات، أكواد LZM، التعديل، Firebase) |
| `logo.js` | شعار الشركة (base64) |
| `images.js` | صورة خلفية الإسعافات (base64) |
| `videos/` | خلفيات الفيديو الضبابية — **ارفع المجلد كاملاً** |

## آخر التحديثات
- ✏️ **تعديل الطلبات**: يفتح نموذج الطلب الأصلي معبأً بكل الخيارات، والحفظ يحدّث نفس الطلب
- استنتاج رمز العميل تلقائياً من كود LZM للطلبات القديمة
- استعادة خيارات الطلبات القديمة من تفاصيلها
- نسخ طلبات الدورات يبدأ بـ "لازم للتدريب — Lazem Training"
- نوع خدمة متعدد في الفعاليات (إسعاف/عيادة/فرقة راجلة/عربة قولف) مربوط بتصنيف الكود
- تصدير Excel، بحث موسّع، ترقيم لا يتكرر، منع تكرار الطلبات

## النشر على GitHub Pages
ارفع **كل** الملفات (بما فيها مجلد `videos`) في جذر المستودع →
Settings → Pages → Branch: `main` → Save

## Firebase
المشروع مربوط بـ `order-management-cef5a`. تأكد أن Firestore منشأة وقواعدها:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{order} { allow read, write: if true; }
  }
}
```
النظام يعمل كاملاً محلياً حتى بدون Firebase ويتزامن تلقائياً عند توفره.
